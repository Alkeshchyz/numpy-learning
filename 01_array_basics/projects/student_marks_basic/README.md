# Student Marks Basic

A beginner NumPy project created to practice the fundamental concepts covered in **Section 01: Array Basics**.

## Objective

Use NumPy to create and inspect a student marks array, perform basic calculations, and work with different data types.

## Student Marks

```python
[45, 78, 92, 67, 88, 34, 95, 73, 81, 59]
```

## Concepts Used

- `np.array()`
- `ndim`
- `shape`
- `size`
- `dtype`
- `astype()`
- `np.mean()`
- `np.max()`
- `np.min()`

## What the Program Does

- Creates a NumPy array containing student marks
- Displays the marks
- Displays the number of students
- Checks the array dimensions
- Checks the array shape
- Checks the total number of elements
- Checks the data type
- Calculates the average marks
- Finds the highest mark
- Finds the lowest mark
- Converts the marks to floating-point values

## Learning Outcome

Through this project, I practiced creating NumPy arrays, inspecting array attributes, converting data types, and performing basic calculations using NumPy.
